AI assistants that understand your Sentry

Give Claude, Cursor, and other MCP-compatible tools safe, structured access to your self-hosted Sentry instance. Triage issues, inspect events, and diagnose projects without leaving your editor.

Get started View release

The problem

Self-hosted Sentry holds critical incident data, but AI tools can't reach it safely.

  • 1
    No API bridge for AI assistants MCP clients have no way to query your self-hosted Sentry without custom integrations.
  • 2
    Raw payloads drown context windows Sentry events are large. Returning full JSON wastes tokens and buries the signal.
  • 3
    Manual triage slows incident response Switching between browser and editor to investigate issues breaks flow and costs time.

What it does

24 MCP tools across 6 functional areas, all designed for token-efficient AI consumption.

Issues

List, get, update, bulk-merge, and bulk-unresolve issues with essential field extraction.

Events

Fetch latest events, breadcrumbs, and stack traces with automatic truncation and filtering.

Releases

List releases, get release details, and check health metrics per project.

Users

Query affected users from events with compact field extraction.

Organization

Org stats, team membership, project lists, and tag values for filtering.

Projects

Project details, key transactions, and diagnostic data for targeted investigation.

Quickstart

Three environment variables, one MCP config entry.

{ "mcpServers": { "sentry": { "command": "npx", "args": ["-y", "@your-org/sentry-selfhosted-mcp"], "env": { "SENTRY_URL": "https://sentry.yourcompany.com", "SENTRY_AUTH_TOKEN": "sntrys_...", "SENTRY_ORG_SLUG": "your-org" } } } }

Requires Node.js 20+. Set SENTRY_URL, SENTRY_AUTH_TOKEN, and SENTRY_ORG_SLUG before starting.

Built for self-hosted

Security and privacy considerations for production use.

✓
No data leaves your instance All API calls go directly to your self-hosted Sentry. No proxy, no third party.
✓
Token-scoped access Uses Sentry auth tokens with configurable scope. No admin credentials stored.
✓
Output filtering by default Every tool extracts only essential fields. Full payloads available on demand with grep filtering.
